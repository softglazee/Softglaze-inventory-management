There are TWO ways to run SoftGlaze. Pick whichever suits you.

================================================================
 OPTION 1 — Desktop app  (easiest, recommended for a single shop)
================================================================
No database, no internet, and no setup required.

  1. Open the   Installer\   folder.
  2. Run        SoftGlaze-Stock-Manager-Setup-{{VERSION}}.exe
  3. Follow the installer, then launch "SoftGlaze Stock Manager".

Windows SmartScreen may warn that the publisher is unknown, because the build is
not code-signed. Choose "More info" then "Run anyway".

On first launch it creates its own private PostgreSQL database, applies the
schema, and seeds defaults automatically. This takes up to a minute the first
time. Register the first account — it becomes the owner / Super Admin — then pick
your business type.

Everything the shop owns (database, uploaded images, settings, logs) lives in:

    %APPDATA%\@softglaze\desktop

Close the app and copy that folder for a complete backup.

================================================================
 OPTION 2 — Self-host / browser  (server + web, e.g. VPS or LAN)
================================================================
Requirements: Node.js 18+ (20 / 22 recommended) and PostgreSQL 14+.

  1. cd Source
  2. npm install
  3. copy  apps\server\.env.example  ->  apps\server\.env
     Edit it: set DATABASE_URL and two strong JWT secrets.
  4. npm run db:migrate
  5. npm run db:seed
  6. npm run dev        (web at http://localhost:5173, API at :4000)

Open http://localhost:5173 and register the first (owner) account.
For production (nginx + PM2 + PostgreSQL, or single-origin mode) see
Documentation\index.html and Source\deploy\README.md.
